# PixelNova

Landing page de una plataforma ficticia de videojuegos, hecha con React, Vite y Bootstrap.
Actividad 1 – Ingeniería Web, UNIMINUTO.

## Cómo ejecutarlo
1. Clona el repositorio: `git clone https://github.com/TU_USUARIO/pixelnova.git`
2. Entra a la carpeta: `cd pixelnova`
3. Instala dependencias: `npm install`
4. Inicia el servidor: `npm run dev`
5. Abre `http://localhost:5173` en el navegador.

## Estructura
Componentes: Navbar, Hero, Categories, FeaturedGames, GameCard, News, Footer.
